## W-001 扇形抽卡動畫

- 狀態：完成（待正式站驗收）
- 範圍：`/draw`、`src/components/DrawDeck/`、`drawSlice`

### 願望

抽卡時，頁面上出現**目前牌庫裡尚未抽出的卡牌**，以**扇形**排列（卡背朝上）。

- **游標移到哪張**，那張卡就進入「即將抽取」的懸停動畫（微微抽出、放大、提高層級）。
- **往上滑動**該張卡，代表抽出它：播放抽卡動畫，再翻開顯示題目。

桌面用游標懸停 + 上滑（或拖曳向上）；觸控用手指按住後上滑。

### 現況

已實作（2026-10-23）。依下方「先洗牌，再對位置」：`drawSlice.dealOrder` 在載入／重設時洗牌一次，扇形第 `i` 張對應第 `i` 張未抽的卡。另加：抽出的卡飛到中央翻面、左上 ✕ 可關閉、滑鼠移到翻開的卡會 3D 傾斜、支援鍵盤與「減少動態」。技術細節見 `docs/architecture.md`「抽牌」。

### 建議作法：先洗牌，再對位置

扇形上每一張「看得見的卡」都要對應牌庫裡一張真正的卡，不要在上滑當下才臨時亂數，否則玩家會覺得「指到的那張」和結果無關。

建議流程：

1. 載入 / 重設牌庫時，把剩餘卡片 **洗牌一次**（Fisher–Yates），得到有序陣列 `dealOrder`。
2. 扇形從左到右（或從中間往兩側）對應 `dealOrder[0]…dealOrder[n-1]`。
3. 游標選到第 `i` 張 → 懸停的就是 `dealOrder[i]`。
4. 上滑抽出 → 翻開 `dealOrder[i]`，並把它加入 `drawnIds`。
5. 抽出後可把該張從扇形拿掉，其餘 magically 收攏；或短暫展示後再回到扇形。

這樣「抽到哪張」完全由**洗牌後的位置**決定，不需要另做亂數 API，也不需要在手勢當下再取一個數字。

若牌很多（例如 50+ 張），扇形會擠在一起。實作時可：

- 只攤開剩餘牌；或
- 超過約 12–16 張時加寬重疊、縮小單張，並讓懸停那張明顯抬起。

### 驗收

- [x] 進入抽卡（牌庫載入後）可見扇形卡背
- [x] 游標移到哪張，哪張有即將抽出的回饋（觸控裝置沒有懸停，按住拖曳時該張會放大跟手）
- [x] 上滑抽出的就是懸停的那張，內容與位置一致（同一輪重現洗牌結果應相同）
- [x] 已抽過的卡不會再出現在扇形中
- [x] 抽完顯示題目；可繼續抽剩餘牌
- [ ] 桌面與觸控都能完成「指向 → 上滑抽出」— 程式已支援，尚未在實機上驗證

### 已決定

- 抽出後：立刻在同頁中央翻面看題，不另開頁。
- 卡背統一，不顯示星級／分類差異。
- 牌太多：扇形最多顯示 12 張，抽走一張就從牌堆補一張。
